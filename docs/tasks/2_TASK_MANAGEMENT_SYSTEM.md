## Objective

Create a mechanism for humans to inject tasks into the project via git and have their status tracked by agents. This enables the workflow: `read CLAUDE.md and implement [the next task|any task|task x]`.

## Requirements

1. Users must be able to store working revisions of tasks in the repository in a draft state
2. Agents should track task state: draft/todo/in_progress/done/blocked
3. Agents shouldn't have to read the entire task text to determine if it should be worked on (frontmatter-only scanning)
4. Multi-agent deduplication: best effort to prevent two agents on different clones from doing duplicate work
5. This capability must be propagated into the harness created by `maslow scaffold/init`
6. Document that ALL harness improvements must be propagated into the scaffold

## Notes

The multi-agent claiming protocol uses git commit-and-push as a distributed lock. This is best-effort, not perfect, but the git conflict on push provides a natural check. Agents that fail to push must re-check task status before retrying.
