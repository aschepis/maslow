## Objective

In order for agents to successfully utilize Maslow to define, build, and verify software we will build an agent skill (https://agentskills.io/specification)

## Requirements

- Create a new agent skill that instructs agents how to use maslow to define, build, and verify software.
  - The skill must be built following the agent skills specification at https://agentskills.io/specification
- new projects (scaffold/init) have the skill automatically added to their project folder.

## Acceptance Criteria

- [ ] A new agent skill has been created that can be used to build software.
- [ ] New maslow projects have the skill automatically added to their project folder.
- [ ] The maslow skill is added to this repo and is available for use by agents.
